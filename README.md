# Climate-Change-Agriculture-Analysis
🌱 Climate Change Impact on Agriculture – Data Analysis

📌 Project Overview

This project analyzes the impact of climate change on agriculture using data analysis techniques with Python and Power BI.

The analysis focuses on understanding how climate-related factors and agricultural conditions are associated with crop productivity and economic impact.

---

📊 Dataset

The dataset contains:

- 10,000 rows
- 15 columns

Main Variables

- Temperature
- Precipitation
- CO₂ Emissions
- Crop Yield
- Extreme Weather Events
- Irrigation Access
- Soil Health
- Economic Impact

---

🛠️ Tools & Technologies

- Python – Data cleaning and analysis
- Power BI – Data visualization and dashboard creation
- CSV – Dataset format

---

🧹 Data Cleaning

Python was used to clean and prepare the dataset before visualization and analysis.

The project presentation includes the data before and after the cleaning process.

---

📈 Power BI Dashboard

The main dashboard presents key agricultural and climate-related indicators, including:

- Total Economic Impact
- Average Crop Yield
- Extreme Weather Events
- Average Soil Health Index
- Total Yield by Crop Type and Country
- Extreme Weather Events Over Years
- Irrigation Access and its comparison with the sustainable target

The analysis shows an average irrigation coverage of 55.25%, compared with an 80% sustainable target.

---

🔍 Key Insights

Based on the analysis:

1. Economic Impact has a strong positive relationship with Crop Yield.
2. Crop performance differs significantly across crop types.
3. Crop Rotation has the highest average yield among the adaptation strategies.
4. Different adaptation strategies can be associated with different yield levels.

---

💡 Recommendations

- Focus on strategies that improve agricultural productivity.
- Consider crop rotation as an adaptation strategy to support productivity.
- Reduce emissions and promote sustainable agricultural practices.
- Increase irrigation access from approximately 55% to 80% to reduce dependency on unpredictable rainfall.
- Support smart adaptation strategies that can improve agricultural performance.
